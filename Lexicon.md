# Lexicon(s)

I currently support a couple of different lexicons (dictionaries). The first is your own custom lexicon, and I also have an Akkadian - Old Babylonian lexicon
that I created based on Harper's translation of the Code of Hammurabi. If you open the Hammurabi lexicon, you can click [+Add] on entries to add them to 
your custom lexicon. 

## Lexicon Per Text
I plan to create lexicons based on a given text, then merge those text-specific lexicons into larger lexicons. I am
still playing with this and trying to think of the best approach. But I like the idea of creating a lexicon for a given text, adding that to a larger
lexicon, then customizing it through my custom lexicon. But I haven't worked out the exact details yet. 

What I like about this is being able to have a lexicon for a given text, then viewing stats and playing with the translations. Then I can merge those into a larger
lexicon and add glosses from multiple translations. So say I have a word that is in Harper's translation of Hammurabi, then I find it in Gilgamesh as well. If they 
have different but similar glosses, I can add both to my custom lexicon or another lexicon such as an Akkadian lexicon, and it will merge the definitions and glosses.

Now when I translate, I can pick the lexicon to use or use the combined lexicon, and I will get the merged glosses in my definitions to review. If I choose to
auto-gloss the text, I should be able to select the lexicons to gloss from. That is not yet implemented, but that is where I am heading with this. 

## Your Custom lexicon(s)
I will support any number of lexicons. For now, I support your custom lexicon and the one I created for Akkadian based on the Code of Hammurabi text. I 
will support import and export to allow you to share lexicons and currently support exporting to Word.
